# Original Office Chair Asset Provenance

This app bundles **Original Office Chair**, a project-original generic
ergonomic office-chair model created procedurally for the RoomPlan tutorial.

- Creation method: AI-assisted procedural Blender Python modeling
- Blender version: 5.1.2
- Third-party mesh data: None
- Third-party textures: None
- Brand names or logos: None
- Reference use: User-supplied office-chair images were used only to understand
  common office-chair proportions and components.
- Excluded details: Distinctive branded topology, repeated back structures,
  logos, and detailed adjustment mechanisms were not reproduced.
- License: CC0 1.0 Universal
- Triangles: 10,496
- Unit: meters
- USD up axis: Y
- Visual front convention: +Z
- Default primitive: Chair
- RealityKit bounds: 0.725 × 1.192 × 0.709 m
- Display materials: Brightened graphite, aluminum, coral, and navy palette
  for readability in the non-AR room overview
- Bundled USDZ SHA-256:
  `7d1c084e4c9d4418bb72892b9fc04161b5ab269f4f9b382824da4089ce993d7d`

The visual-front value describes this asset's modeling convention. RoomPlan
doesn't guarantee the semantic front or back of a detected chair.
